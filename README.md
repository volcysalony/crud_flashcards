# 📚 CRUD de Flashcards em Node.js

## 📌 Descrição

Este projeto consiste em um sistema de gerenciamento de **flashcards e baralhos**, desenvolvido em Node.js, com o objetivo de aplicar os conceitos de **CRUD (Create, Read, Update, Delete)**, organização de código e trabalho em equipe utilizando Git e GitHub.

O sistema funciona via terminal, permitindo ao usuário interagir por meio de um menu interativo.

---

## 🚀 Funcionalidades

### 📥 CREATE

* Adicionar baralho
* Adicionar flashcard

### 📖 READ

* Listar baralhos
* Listar todos os flashcards
* Listar flashcards por baralho

### ✏️ UPDATE

* Atualizar título de baralho
* Atualizar pergunta e resposta de flashcard

### 🗑️ DELETE

* Remover baralho (com exclusão em cascata dos flashcards)
* Remover flashcard individual

### 🔍 BUSCA

* Buscar flashcards por pergunta

## ▶️ Como Executar o Projeto

### 1. Clonar o repositório

```bash
git clone https://github.com/volcysalony/crud_flashcards.git
```

### 2. Acessar a pasta

```bash
cd crud_flashcards
```

### 3. Instalar dependências

```bash
npm install
```

### 4. Executar o sistema

```bash
node index.js
```
